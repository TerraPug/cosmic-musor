Офлайн-проверка ввода: `dotnet run --project Tests/InputContract/InputContract.csproj`.

Компилирует настоящие SpaceGameInput и SpacePlayerController с контрактными заглушками Unity.
Вызывает Awake, Start, Update и FixedUpdate контроллера. Старый Input API намеренно
выбрасывает исключение: контроллер не должен обращаться к нему при активном новом backend.
Проверяет движение, обзор, нормализацию диагонали, Esc, повторный захват курсора,
независимые кнопки клешней, потерю фокуса и отключение/возвращение устройств.

Это не Play-тест: реальная обработка устройств, физика и захват предметов требуют проверки в Unity.
