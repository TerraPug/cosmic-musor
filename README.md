## Версия Unity

Открывайте проект в Unity 6000.6.3f1 (revision 45d8eee7de74).
Зависимости и настройки URP согласованы с этой версией редактора.
Не открывайте проект в более старой Unity: она может перезаписать packages-lock.json и настройки графики.
